Research that frontier labs build on

Benchmarks, environments, and systems that are used outside the lab: in frontier-model training and evaluation, by large open-source communities, and in hyperscale production.

Agentic RL training · GLM-5

RepoLaunch builds executable environments for GLM-5

“We employ an environment setup pipeline based on the RepoLaunch framework that scales the construction of executable environments from real-world SWE issues.”

— GLM-5 Technical Report, Zhipu AI / Z.ai (arXiv 2602.15763)

RepoLaunch is the first agent that resolves dependencies, compiles code, and extracts test results for any language on any OS: C/C++, C#, Python, Java, JS/TS, Go, and Rust, on Linux and Windows. It was used to build 10,000+ Docker environments for large-scale agentic training.

03 — Projects

Selected projects

LedNeurIPS 2025 · D&BarXiv 2026

SWE-bench-Live & RepoLaunch

A continuously updated issue-resolution benchmark, built by an automated pipeline. RepoLaunch is an agent that sets up, builds, and tests any repository, in any language, on Linux or Windows. It turns real GitHub issues into verified, reproducible Docker tasks with no human in the loop. The latest pipeline reaches ≥98% build/test success at 82% lower LLM cost.

UFO series: Desktop AgentOS

UFO was a pioneering UI-focused agent for Windows. UFO² turned it into a multi-agent Desktop AgentOS (HostAgent + AppAgents, hybrid GUI–API actions), and UFO³ connects agents across devices into a “digital agent galaxy.” Related work includes a widely cited survey of LLM-brained GUI agents, a study of how API and GUI agents diverge and converge, and the GUI-360° dataset.
